# Music

The game plays a quiet generated score by default. To use recorded music
instead, put MP3 files in this folder with these names. Any that are missing
keep the generated score.

| File         | Plays                                  |
|--------------|----------------------------------------|
| `story.mp3`  | Prologue                               |
| `home.mp3`   | Home                                   |
| `kost.mp3`   | Kost Melati                            |
| `campus.mp3` | Campus                                 |
| `hq.mp3`     | PayVault HQ                            |
| `fight.mp3`  | Warden encounters                      |
| `finale.mp3` | The confrontation in the Briefing Room |

Tracks loop, so pick ones that loop cleanly, and only use music you have the
right to ship.
